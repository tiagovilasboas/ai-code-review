Quickstart

Run the review on a unified diff. The process exits with code 1 when any finding is BLOCK.

Go CLI

The Go port is in progress. From a checkout of the repository:

go run ./cmd/review examples/sample-pr.diff

Once the port is merged, install it with:

go install github.com/tiagovilasboas/ai-code-review/cmd/review@latest

Node CLI

Requires Node 18 or later. No LLM and no network access are needed.

npm run review -- examples/sample-pr.diff

Read the output

The report starts with a decision and a reason. Each finding lists its class, evidence as path:line, CWE, OWASP identifiers, severity and action.

Decision: DO NOT MERGE
Reason: AuthZ/IDOR at src/api/orders.ts:36 (ASVS-5.0-8.2.2)

Finding: Hardcoded credential in source
Class: Secret in source
Evidence: config/app.ts:14
CWE: CWE-798
OWASP: A02:2021, ASVS-5.0-13.3.1
Severity: CRITICAL
Action: BLOCK

Finding: Missing object-level authorization
Class: AuthZ/IDOR
Evidence: src/api/orders.ts:36
CWE: CWE-639
OWASP: A01:2021, API1:2023, ASVS-5.0-8.2.2
Severity: HIGH
Action: BLOCK

Finding: Overly permissive CORS origin
Class: CORS misconfiguration
Evidence: src/server.ts:8
CWE: CWE-942
OWASP: A05:2021, ASVS-5.0-3.4.2
Severity: MEDIUM
Action: REVIEW

Exit codes

CodeMeaning
0No BLOCK finding
1At least one BLOCK finding. Do not merge.
